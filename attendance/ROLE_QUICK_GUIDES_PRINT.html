Role Quick Guides

Print-friendly version for team training and onboarding.

1) HR Admin

Daily start

  1. Login and open Attendance, Geo Alerts, Biometrics.
  2. Check Integrations sync health.

Staff setup

  1. Open Staff & Sites.
  2. Create/update staff ID, role, site, shift.
  3. Save and verify.

Face enrollment

  1. Open employee profile.
  2. Capture face in good lighting.
  3. Confirm enrolled status.

Odoo routing

  • Operational staff: active route (`dxb`/`auh`).
  • HR/vehicle/test records: excluded.

2) Site Supervisor

Daily start

  1. Open Live Map and Attendance.
  2. Review Geo Alerts and Location Logs.

During shift

  1. Monitor routes and idle behavior.
  2. Escalate attendance/profile issues to HR Admin.

End of shift

  1. Verify expected staff checked out.
  2. Document exceptions.

3) Employee

Login

  1. Enter staff ID.
  2. Use face login (or PIN fallback if enabled).

Attendance

  1. Tap Face Check-In at shift start.
  2. Tap Face Check-Out at shift end.

If face fails

  • Improve lighting and face framing.
  • Retry with a slow blink.
  • Contact supervisor/HR if repeated failures.

4) Kiosk Operator

One-time setup

  1. Open /kiosk/{siteId}.
  2. Enter kiosk deviceKey.
  3. Confirm camera access.

Per attendance action

  1. User taps Check-In or Check-Out.
  2. System identifies face (1:N).
  3. Verify success message + staff ID.

Common errors

  • Unknown device: verify key assignment.
  • No match: verify enrollment quality.

5) IT / System Admin

Health checks

  1. Confirm `attendance_api`, `attendance_web`, `attendance_db`, `attendance_redis` healthy.
  2. Confirm `https://attendance.berkeleyuae.com` returns `200`.
  3. Confirm API `GET /healthz` returns `{ "ok": true }`.

Deploy/update

  1. Pull latest code.
  2. Run production compose build/up.
  3. Run smoke checks (HR login, enrollment, kiosk, reports, sync).

Operations

  • Monitor errors, sync status, and device health.
  • Maintain secrets and backup/restore cadence.

6) Daily Go-Live Checklist

  1. Public app reachable and secure.
  2. HR login and staff management work.
  3. Employee face check-in/out works.
  4. Kiosk check-in/out works.
  5. No active Odoo sync failures.
  6. Biometric devices healthy.
  7. Alerts reviewed and acknowledged.

7) Escalation Matrix

  • Attendance/face issue: Employee -> Site Supervisor -> HR Admin
  • Routing/integration issue: HR Admin -> IT Admin
  • System/network/proxy issue: IT Admin

# Performance Management

Complete guide to tracking and evaluating guard performance in GuardPro.

---

## Overview

Performance Management helps you monitor guard effectiveness, conduct reviews, track KPIs, record commendations, and manage disciplinary actions.

---

## Performance Metrics

### Key Performance Indicators (KPIs)

**Attendance Metrics:**
- Attendance rate (%)
- On-time percentage
- No-show count
- Overtime hours

**Patrol Compliance:**
- Checkpoint scan rate
- Route completion rate
- On-schedule patrols
- Missed checkpoints

**Incident Response:**
- Incidents reported
- Response time
- Resolution quality
- Client feedback scores

**Overall Rating:**
- Composite score (1-5 stars)
- Peer rankings
- Supervisor ratings
- Client satisfaction

## Performance Reviews

### Scheduling Reviews

**Review Frequency:**
- **Probation Period:** Monthly (first 90 days)
- **Regular Employees:** Quarterly
- **Annual Review:** Comprehensive yearly review
- **Ad-hoc:** As needed for issues/promotions

### Conducting a Review

**Step 1:** GuardPro > Performance Reviews

**Step 2:** Click **"Schedule Review"**

**Step 3:** Fill review details:

| Field | Description |
|-------|-------------|
| **Guard** | Select guard |
| **Review Type** | Probation/Quarterly/Annual |
| **Review Date** | Scheduled date |
| **Reviewer** | Supervisor conducting review |
| **Location** | Where review will occur |

**Step 4:** System creates review template

**Step 5:** Complete evaluation sections:

**A. Attendance & Punctuality**
- Rating: 1-5
- Comments
- Areas for improvement

**B. Job Knowledge**
- Understanding of duties
- Procedure compliance
- Training completion

**C. Quality of Work**
- Thoroughness
- Attention to detail
- Report quality

**D. Professionalism**
- Appearance
- Communication
- Client interaction

**E. Problem Solving**
- Initiative
- Decision making
- Crisis handling

**F. Teamwork**
- Cooperation
- Support to colleagues
- Team contribution

**Step 6:** Set goals for next period

**Step 7:** Guard signs (electronic signature)

**Step 8:** Save and finalize

## Recording Commendations

### When to Issue

- Exceptional performance
- Client praise
- Incident prevention
- Going above and beyond
- Assistance to colleagues
- Training excellence

### How to Record

**Step 1:** Open guard profile

**Step 2:** Click **"Add Commendation"**

**Step 3:** Fill details:

| Field | Description |
|-------|-------------|
| **Date** | When action occurred |
| **Type** | Outstanding Performance/Client Praise/Other |
| **Description** | Detailed account |
| **Issued By** | Your name (supervisor) |
| **Witnesses** | If any |
| **Recognition** | Letter/Certificate/Bonus/Promotion |

**Step 4:** System actions:
- Added to performance record
- Certificate generated
- Guard notified
- Shared with management
- Considered for promotions/raises

## Managing Disciplinary Actions

### Progressive Discipline Steps

**Level 1: Verbal Warning**
- Informal discussion
- Document conversation
- Set expectations
- No formal record

**Level 2: Written Warning**
- Formal documentation
- Specific violations listed
- Improvement plan
- Timeline for correction
- Consequences outlined

**Level 3: Suspension**
- Temporary removal from duty
- Investigation period
- Loss of pay (typically)
- Formal hearing

**Level 4: Termination**
- Employment ended
- Final paycheck processed
- Exit procedures
- Equipment return

### Recording Disciplinary Action

**Step 1:** GuardPro > Guards > Disciplinary Actions

**Step 2:** Click **"New Action"**

**Step 3:** Fill form:

| Field | Mandatory | Description |
|-------|-----------|-------------|
| **Guard** | ✅ Yes | Select guard |
| **Violation Type** | ✅ Yes | Category of issue |
| **Severity** | ✅ Yes | Minor/Moderate/Serious/Severe |
| **Action Level** | ✅ Yes | Warning/Suspension/Termination |
| **Incident Date** | ✅ Yes | When violation occurred |
| **Description** | ✅ Yes | Detailed account |
| **Policy Violated** | ✅ Yes | Specific policy reference |
| **Witnesses** | ❌ No | Names of witnesses |
| **Evidence** | ❌ No | Photos/documents/reports |
| **Improvement Plan** | ✅ Yes | Steps for correction |
| **Follow-up Date** | ✅ Yes | When to review progress |

**Violation Types:**
- Attendance issues
- Tardiness
- Uniform violations
- Insubordination
- Policy violations
- Performance issues
- Client complaints
- Safety violations
- Theft/dishonesty

**Step 4:** Guard reviews and signs

**Step 5:** HR copy filed

**Step 6:** Follow-up scheduled

## Performance Improvement Plans

### Creating a PIP

**When Needed:**
- Consistent underperformance
- After written warning
- Skills gaps identified
- Client concerns raised

**PIP Components:**

**1. Performance Issues:**
- Specific problems
- Impact on operations
- Frequency/severity

**2. Expected Standards:**
- Clear performance targets
- Measurable goals
- Realistic timelines

**3. Support Provided:**
- Additional training
- Mentoring assigned
- Resources available
- Regular check-ins

**4. Measurement:**
- How progress tracked
- Reporting frequency
- Success criteria

**5. Consequences:**
- What happens if goals met
- What happens if not met
- Timeline for decision

**Typical PIP Duration:** 30-90 days

## Best Practices

### Regular Feedback

✅ **Do:**
- Provide immediate positive feedback
- Address issues promptly
- Be specific with examples
- Focus on behaviors, not personality
- Document everything
- Be consistent across all guards

❌ **Don't:**
- Wait for annual review
- Use hearsay without verification
- Compare guards publicly
- Hold grudges
- Surprise guards with reviews
- Ignore small issues

### Recognition Programs

**Ideas:**
- Guard of the Month
- Perfect Attendance Awards
- Safety Achievement Recognition
- Client Praise Spotlight
- Years of Service Awards
- Team Excellence Awards

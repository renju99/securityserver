# Introduction to GuardLink

Welcome to GuardLink - Enterprise Security Guard Management System

---

## What is GuardLink?

GuardLink is a comprehensive platform for managing security guard operations, from scheduling and attendance to incident reporting and compliance management.

- Operations Managers

## Key Concepts

### Guards
Security personnel who provide on-site services

### Sites
Client locations where security services are provided

### Shifts
Scheduled time periods when guards are assigned to sites

### Incidents
Security events that require documentation and response

### Checkpoints
Physical locations that guards scan during patrols

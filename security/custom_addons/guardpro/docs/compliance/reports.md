# Daily Activity Reports (DAR)

Complete guide to creating and managing Daily Activity Reports in GuardLink.

---

## Overview

Daily Activity Reports (DARs) document all guard activities, observations, and incidents during their shift, providing a comprehensive record for client accountability and operational review.

---

## Creating a DAR

### Navigation
- GuardLink > Compliance > Daily Reports
- Click **"Create Report"**

### Report Information

| Field | Mandatory | Description |
|-------|-----------|-------------|
| **Report Date** | ✅ Yes | Date of report |
| **Shift** | ✅ Yes | Which shift |
| **Site** | ✅ Yes | Location |
| **Guard** | ✅ Auto | Reporting guard |
| **Supervisor** | ✅ Auto | Reviewing supervisor |

---

## Report Sections

### 1. Shift Summary

**What to Include:**
- Start time and end time
- Weather conditions
- Overall site status
- Any notable events
- General observations

**Example:**
```
Shift: 6:00 PM - 6:00 AM
Weather: Clear, 15°C
Site Status: Secure, no incidents
Notable: Increased vehicle traffic due to nearby event
```

### 2. Patrol Activities

**Document:**
- Checkpoints scanned
- Patrol routes completed
- Times of patrols
- Any issues found
- Corrective actions taken

**Example:**
```
22:00 - Completed full perimeter patrol
       All doors secured
       Exterior lighting functional
       No unauthorized vehicles observed
```

### 3. Incidents

**Link to incident reports:**
- Brief summary
- Reference incident number
- Action taken
- Follow-up required

### 4. Visitor Log

**Record:**
- All visitors
- Check-in/check-out times
- Purpose of visit
- Badges issued/returned

### 5. Key/Equipment Log

**Document:**
- Keys signed out/returned
- Equipment issued
- Maintenance needed
- Lost/damaged items

### 6. Unusual Observations

**Note anything unusual:**
- Suspicious activity
- Property conditions
- Safety concerns
- Maintenance issues
- Noise complaints

**Example:**
```
01:30 - Noticed flickering light in parking lot section C
        Reported to maintenance via ticket #1234
03:15 - Heard unusual noise from loading dock area
        Investigated - discovered loose door chain
        Secured and noted for repair
```

###7. Communications

**Log all communications:**
- Supervisor contacts
- Client calls
- Emergency services
- Maintenance requests
- Other guards

---

## Completing the DAR

### Before Submission

**Checklist:**
- ✅ All sections completed
- ✅ Incidents linked
- ✅ Times accurate
- ✅ Clear and professional language
- ✅ No spelling errors
- ✅ Photos attached if applicable
- ✅ Signatures obtained

### Submission Process

**Step 1:** Review all entries

**Step 2:** Click **"Submit for Review"**

**Step 3:** Supervisor receives notification

**Step 4:** Supervisor reviews and:
- Approves
- Requests revisions
- Adds supervisor notes

**Step 5:** Final approval

**Step 6:** Automatically sent to client (if configured)

---

## DAR Templates

### Using Templates

**Benefits:**
- Consistency across guards
- Faster completion
- Standard format
- Required sections included

**Creating Templates:**
- GuardLink > Configuration > DAR Templates
- Define sections
- Set required fields
- Assign to sites

---

## DAR Reports

### Available Reports

**1. Daily Report Summary**
- All DARs for date range
- By site or guard
- Highlight issues

**2. Monthly Activity Report**
- Aggregate data
- Trend analysis
- Client summary

**3. Incident Summary**
- All incidents from DARs
- Categorized
- Action status

---

## Best Practices

✅ **Do:**
- Complete DAR at end of shift
- Be detailed and specific
- Use professional language
- Note times accurately
- Include all incidents
- Proofread before submitting

❌ **Don't:**
- Leave sections blank
- Use abbreviations clients won't understand
- Include personal opinions
- Skip minor observations
- Submit late
- Copy previous day's report

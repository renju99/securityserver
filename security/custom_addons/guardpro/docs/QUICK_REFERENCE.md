## 🔑 Login & Access

### Web Portal Access
```
URL: https://your-domain.com/web/login
Username: [Guard ID or Email]
Password: [Assigned password]
```

### Mobile App Access
```
PWA URL: https://your-domain.com/guardpro/mobile
Install: Tap "Add to Home Screen" in browser
Offline: Works without internet connection
```

### Password Reset
1. Click "Reset Password" on login page
2. Enter your email address
3. Check email for reset link
4. Set new password (minimum 8 characters)

## 👮 Guard Operations

### Daily Check-in/Check-out
```
Morning: Tap "Check In" → Select shift → Confirm location
Evening: Tap "Check Out" → Review hours → Submit report
```

### Checkpoint Scanning
```
QR Code: Open camera → Point at QR code → Auto-scan
NFC Tag: Tap phone to NFC tag → Confirm location
Manual: Enter checkpoint code manually
```

### Patrol Routes
```
Start Tour: Select assigned tour → "Start Patrol"
Navigate: Follow GPS directions or manual navigation
Scan Points: Scan checkpoints as you reach them
Complete: "End Patrol" → Auto-generate report
```

### Incident Reporting
```
Quick Report: Camera icon → Photo → Location → Description
Emergency: Red panic button → Auto-alert supervisors
Follow-up: Add details → Assign investigation → Notify client
```

## 🚨 Emergency Procedures

### Panic Button Activation
```
1. Press and hold red panic button for 3 seconds
2. System auto-sends alert to supervisors + emergency contacts
3. GPS location automatically shared
4. Stay in safe location until help arrives
```

### Emergency Codes
```
Code Red: Fire emergency - Evacuate and call 999
Code Blue: Medical emergency - Call 999, provide first aid
Code Black: Active threat - Lock down, call police
Code Yellow: Suspicious activity - Monitor and report
```

### Emergency Broadcast
```
Initiate: Menu → Emergency Broadcast → Select template
Recipients: Choose guards, supervisors, or all personnel
Message: Pre-written or custom emergency message
Confirm: Send immediately with push notifications
```

## 💡 Pro Tips

### 🔋 Battery Management
- Keep battery above 20% for GPS tracking
- Use power saving mode during long shifts
- Charge during breaks when possible

### 📍 GPS Accuracy
- Ensure location services are enabled
- Clear view of sky for better accuracy
- GPS works indoors with WiFi positioning

### 📱 Data Usage
- Photos compress automatically to save data
- Offline mode reduces data consumption
- Large reports sync during WiFi connections

### 🔒 Security Best Practices
- Never share login credentials
- Log out when not using device
- Report lost/stolen devices immediately
- Use biometric authentication when available

## 🔧 Troubleshooting

### Common Issues
```
GPS not working: Check location permissions → Restart app
Camera not scanning: Clean lens → Check lighting → Restart camera
App not loading: Clear cache → Check internet → Reinstall app
Sync failed: Check connection → Manual sync → Contact support
```

### Quick Fixes
```
App frozen: Force close → Restart
Location inaccurate: Wait for GPS fix → Move to open area
Notifications missing: Check app permissions → Restart device
Login failed: Reset password → Check credentials
```

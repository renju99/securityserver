# Patrol Routes

Complete guide to creating and managing patrol routes in GuardLink.

---

## Overview

Patrol Routes allow you to define scheduled routes that guards follow, including multiple checkpoints in a specific sequence to ensure comprehensive site coverage.

---

## Creating Patrol Routes

### Navigation
- GuardLink > Site Management > Patrol Routes
- Click **"Create"**

### Route Information

| Field | Mandatory | Description |
|-------|-----------|-------------|
| **Route Name** | ✅ Yes | Descriptive route name |
| **Site** | ✅ Yes | Location site |
| **Route Type** | ✅ Yes | Perimeter/Interior/Mixed |
| **Estimated Duration** | ✅ Yes | Time to complete |
| **Frequency** | ✅ Yes | How often per shift |

---

## Adding Checkpoints to Route

### Step-by-Step:
1. Click **"Add Checkpoint"**
2. Select checkpoint from list
3. Set sequence order
4. Define time window
5. Add specific instructions
6. Save checkpoint to route

---

## Route Scheduling

### Assign to Shifts
- Select which shifts use this route
- Set number of completions required
- Define acceptable time windows
- Configure alerts for missed patrols

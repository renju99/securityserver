# Site Setup

Complete guide to creating and configuring client sites in GuardLink.

---

## Overview

Site Setup allows you to create and manage security service locations including client sites, buildings, and facilities where guards provide security services.

---

## Creating a New Site

### Navigation
- GuardLink > Site Management > Sites
- Click **"Create"**

### Basic Information

| Field | Mandatory | Description |
|-------|-----------|-------------|
| **Site Name** | ✅ Yes | Client site name |
| **Site Code** | ✅ Yes | Unique identifier |
| **Client** | ✅ Yes | Client company |
| **Address** | ✅ Yes | Complete address |
| **Site Type** | ✅ Yes | Commercial/Residential/Industrial |
| **Operating Hours** | ✅ Yes | When site operates |
| **Guard Requirements** | ✅ Yes | Number of guards needed |

**How to Fill:**
1. Enter site name and code
2. Select client from dropdown
3. Fill complete address
4. Set operating schedule
5. Define security requirements
6. Save site

---

## Site Configuration

### Access Control Settings
- Gate access rules
- Badge requirements
- Visitor policies
- Restricted areas

### Emergency Contacts
- Site manager
- Client contact
- Emergency services
- Backup contacts

### Security Requirements
- Number of guards per shift
- Required certifications
- Special equipment needed
- Uniform requirements
